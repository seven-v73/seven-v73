## Selected Projects

### [CocoMarket](https://github.com/seven-v73/CocoMarket)

An asynchronous retail management system designed to connect multiple stores and checkout terminals to a central administration platform.

The project explores offline-oriented sales processing, message-based communication, stock synchronization, duplicate handling, reconciliation, and operational resilience.

**Focus:** Python · Flask · RabbitMQ · PostgreSQL · SQLite · Docker · Prometheus · Distributed Systems

### [Seven Control / MDM_System](https://github.com/seven-v73/MDM_System)

A device management and monitoring project built around educational environments.

It explores computer inventory, remote administration, monitoring, and operational workflows for managing learner devices. The repository includes Veyon upstream components alongside additional Seven Control development.

**Focus:** C++ · Linux · Windows · Networking · Device Management · Automation

### [MonBaobab](https://github.com/seven-v73/BAOBAB)

A digital platform focused on African cultures, heritage, and communities.

The project brings together content, community features, commerce, and administration through a full-stack architecture.

**Focus:** React · TypeScript · Node.js · Express · MongoDB · APIs

### [ElegantStyle](https://github.com/seven-v73/elegantfaso)

A Flutter-based fashion marketplace and styling platform connecting users, creators, and shops.

The project explores mobile application development, multi-role experiences, and service-oriented application features.

**Focus:** Flutter · Firebase · Mobile Engineering · Commerce · Multi-role Architecture

### [Le Grin](https://github.com/seven-v73/le-grin)

A platform prototype built around learning paths, mentorship, companies, and member spaces.

**Focus:** Next.js · Express · Prisma · PostgreSQL · Platform Architecture

### SevenOS — Personal Systems Project

SevenOS is a private, Linux-based system experience project built around Arch Linux and Hyprland.

It explores how a computing environment can adapt to different user contexts and system conditions through distinct operating identities, automation, resource-aware behavior, and controlled execution.

Its architecture includes a central Adaptive Core and Seven Bridge, a component designed to connect with external systems through SSH and SFTP.

**Focus:** Linux · Rust · Systems Architecture · Automation · Adaptive Computing

*The source code is currently private.*

## Engineering Principles

The way I approach engineering is guided by a few principles:

- **Fundamentals before frameworks** - understand the principles behind the tools.
- **Understanding before implementation** - know the problem before choosing a solution.
- **Systems thinking** - consider interactions, dependencies, and constraints.
- **Reliability by design** - think about failure, security, and maintainability from the beginning.
- **Practical engineering** - build solutions that address real needs.
- **Continuous learning** - learn, experiment, evaluate, and improve.

> Go beyond using technology. Understand how it works, why it works, and where it can fail.
